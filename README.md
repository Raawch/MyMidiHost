<h1 align="center">My MIDI Host</h1>

<p align="center">
  A simple, clean MIDI host that runs in your browser.<br>
  Connect a USB MIDI keyboard or controller to synths and devices that have no MIDI DIN ports, no computer needed.
</p>

<p align="center">
  <a href="https://raawch.github.io/MyMidiHost/"><b>▶ Launch the app</b></a>
</p>

## Features
- Route multiple MIDI inputs to multiple outputs, with input and output channel selection
- Velocity curve presets, a fixed velocity option, and a custom curve editor
- Built-in 2 octave keyboard with transpose and scale selection
- Transpose and scale can also be applied to your MIDI input device
- Installs as an app and works fully offline, great for dawless setups

## Getting started
1. Open the link above in **Chrome** on Android or desktop.
2. Tap the **Install** button at the top to use it offline. If it doesn't appear, install it from Chrome's address bar or select **⋮** menu, then **Cast, Save and Share** on Chrome desktop or **Add to home screen** on Android.
3. Plug in your devices (on Android you'll need a USB OTG adapter and a USB hub if connecting more than one device) and allow the MIDI permission prompt.
